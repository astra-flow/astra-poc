# 灵犀敏捷转型下一步 — 讨论提纲

## 背景

灵犀规模化敏捷跑了两年，流程跑通了，但继续深入遇到了两个问题：

1. 战队成熟度没有统一标准——敏捷教练说好，职能总监说不好，各说各的
2. 多项目之间没有优先级规则——资源分配靠人催，谁催得急谁先上

## 推进路线

| 步骤 | 做什么 | 关键产出 |
|------|--------|---------|
| 1. 启动认证 | 启动 SEMM 成熟度评估，拿到 31 个战队的基线数据 | 评估报告 + 差距分析 |
| 2. 流程升级 | 根据评估结果，把灵犀规模化敏捷流程进一步系统化 | 升级版流程文档 + 配套工具 |
| 3. 拿证宣传 | 完成认证，作为 SAFe/Scrum.org Customer Story 对外宣传 | 认证证书 + 案例发布 |
| 4. 方法论共创 | 与 Scrum.org.cn 联合，定义汽车行业 AI Native + 规模化敏捷成熟度评估体系 | 行业标准白皮书 |
| 5. 行业协会 | 联合兄弟单位，成立汽车行业敏捷联盟，对外赋能 | 行业协会 + 商业项目 |

## 具体事项

| 事项 | 归属步骤 | 说明 |
|------|---------|------|
| SEMM 认证 | 步骤 1-3 | 预算 20 万，需确认 |
| Scrum.org.cn 合作 | 步骤 1-4 | 对方出方法论和认证资质，我们出实战场景 |
| 内部流程升级 | 步骤 2 | 投资组合管理机制、流程文档化 |
| 信通院对接 | 步骤 4-5 | 朝阳总协调 |
| 行业标准共创 | 步骤 4 | 基于灵犀实践 + SEM 体系 |
| 外部课程（丰田/奔腾） | 步骤 5 | 投入小、有现金流 |
