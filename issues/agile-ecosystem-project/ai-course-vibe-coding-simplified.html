Vibe Coding 实战工作坊

2 天 · 用 AI 做出可复用、可迭代的电商运营工具

一、课程概览

项目说明
时长2 天（每天 7 小时）
学员已有 AI 使用基础，能手搓 HTML 或小工具
Day 1掌握 Vibe Coding 系统方法，独立完成一个电商场景小应用
Day 2学会沉淀可复用经验，团队协作完成 Hackathon 项目

学员画像：数据运营、直播运营、客服岗位，平均 28 岁。核心诉求——从"能写出代码片段"升级到"能独立交付完整可用的应用，并让经验可复用"。

二、课程安排

Day 1：Vibe Coding 系统化
1

开场：Vibe Coding 是什么

从 Andrej Karpathy 2025 年创造的概念讲起——用自然语言描述意图，AI 生成代码，你来审查和迭代。

2

结构化 Prompt 工程

从"随手写 prompt 碰运气"到"结构化描述，效果稳定可预期"。实操：用结构化方法重写课前作业，对比差异。

3

工具链实操

从需求描述到一键部署的全流程。讲师演示 + 学员跟做，确保每人跑通完整链路。实操：搭建「电商数据查询工具」，30 分钟内拿到可分享链接。

4

电商场景深度实战

覆盖数据运营（日报自动化）、直播运营（数据看板）、客服（智能知识库）、通用（竞品监控）四大场景。每人选自己岗位的场景搭建 MVP。

5

成果展示 + 组队

每人展示 Day 1 作品，讲师点评。自由组队，为 Day 2 Hackathon 选题。

Day 2：经验沉淀 + Hackathon
6

把经验沉淀为可复用模板

你脑子里知道怎么做，但 AI 不知道——怎么让 AI 知道？讲解如何把数据口径、设计规范、常见坑写成 AI 可读的知识模板。实操：为 Day 1 的项目写模板，再用模板让 AI 重新生成，对比前后差异。

7

团队 Hackathon

2-3 人一组，电商场景自由选题。要求：必须部署上线 + 产出至少一个可复用模板。推荐选题：直播数据看板、客服知识库 chatbot、大促作战指挥屏、运营日报自动生成器、差评智能分析工具。

8

项目展示 + 总结

每组演示 + 点评。讲师总结高频问题与最佳实践。课后作业：完善项目 + 收集改进点。

四、Vibe Coding 的局限

Vibe Coding 显著降低了软件开发的门槛，让非技术人员也能快速实现想法。但 Karpathy 在提出这个概念时也明确指出，它更适合"周末小项目"。当应用数量增多、团队规模扩大后，以下问题会逐渐显现：

能解决的暂时解决不了的
一个人快速搭建工具团队多人协作时，输出质量参差不齐
单次对话完成一个功能需求变更后，AI 缺乏对历史上下文的持续理解
快速验证想法、做出 Demo代码质量、安全性、可维护性的系统保障
凭个人经验写 prompt将经验体系化，让团队稳定复现

这些问题并非 Vibe Coding 的缺陷，而是它的边界。当团队需要跨越这个边界时，需要一套更系统的方法——智能体工程。
